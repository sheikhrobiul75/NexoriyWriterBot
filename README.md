# Nexoriy AI Writer Bot

🤖 Nexoriy AI Writer Bot is an AI-powered Telegram bot that helps users create SEO-optimized blog content.

## Features

- SEO Title Generator
- Low Competition Keyword Suggestions
- Human-like Long Articles (6000–7000 words)
- Meta Description
- SEO Labels
- Permalink Generator
- Image Title
- Image File Name
- Image Alt Text
- Thumbnail Prompt
- AI Content Assistant

## Tech Stack

- Python 3
- python-telegram-bot 21.6
- Render
- GitHub

## Commands

```
/start
```
